# Make the import desk yours

Read CLAUDE.md and docs/cli.md. Ask which field or rule the operator wants. Read the existing mappings, affected batch and migrations. For a field rule, write a new immutable mapping version with add-mapping, then import a new test batch. Do not edit old mapping definitions. For a persistent domain field, write the next numbered migration with a default or backfill, run migrate in a disposable database, extend the CLI and tests, and demonstrate the new query. Run npm test. Apply the migration to the intended database only within the operator's authorised scope, with a backup. Present the actual before and after results. Never invent output or silently drop source columns.
