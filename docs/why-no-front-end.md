# Why this is an operator's desk

A data import lead asks what is blocked, corrects a field, records why a row is excluded, and asks a colleague to approve a clean batch. Those actions work through a coding agent and one CLI. Read-only HTML shows the week, field errors and recorded controls. Branded HTML produces correction requests, acceptance records and handover manifests.

A screen adds visual column matching, spreadsheet editing and customer self-service. Mobile uploads, offline browser work, Excel ingestion, embedded widgets and live feeds are not supplied by the free base. Enterprise DNA can build those around the agreed workflow. This base is useful on its own for an operator working from CSV result files. It does not replace every Dromo deployment.

No web server or sending service runs here. View and document commands use read-only database transactions. Generated reports contain private records and must remain in controlled storage.
